# bank-checker
This is just a fun little Python project I made while learning how to code. I honestly don't know why I decided to make a bank simulator, but I thought it would be fun to experiment with what I've learned so far.

The program asks for your name, bank balance, budget, and the price of a MacBook. It then uses comparison operators and if/else statements to check different values.

It's nothing advanced, and I'm still a beginner, but I made it myself to practice Python and see what I could build with my current knowledge.

Just a random project for fun and practice!
